# ♨️ ТеплоПак — лендінг + CRM-бот для замовлень

Односторінковий сайт для продажу **багаторазових сольових грілок** та Telegram-бот із базовою CRM: номери замовлень, клієнти, доставка, ТТН, коментарі, статуси й статистика.

---

## 🧭 Як це працює

```
Сайт (index.html)
      │  POST /api/order  (X-API-Key)
      ▼
CRM-бот (bot/) ── SQLite (bot/data/orders.db)
      │
      ▼
Telegram: картка замовлення з кнопками
   ├─ статуси: нове / опрацювання / доставка / успішно / відміна
   ├─ ТТН
   ├─ коментарі менеджера
   ├─ /stats — статистика
   └─ /export — CSV
```

Кожне замовлення з сайту отримує **номер (№1001, №1002…)** і зберігається в базі. Навіть якщо повідомлення в Telegram не дійде, замовлення не втрачається.

## ⚡ Швидкий старт (5 хвилин)

### 1. Створіть бота
1. [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюйте **токен**.
2. [@userinfobot](https://t.me/userinfobot) → `/start` → скопіюйте свій **ID**.
3. Обов'язково натисніть **/start** у своєму новому боті.

### 2. Налаштуйте бота
```bash
cd bot
cp .env.example .env
```
У `bot/.env` заповніть:
```env
BOT_TOKEN=1234567890:AA...
ADMIN_IDS=123456789
ADMIN_CHAT_ID=123456789
SITE_API_KEY=sk_live_довгий_випадковий_рядок
```

### 3. Запустіть бота
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```
Або через Docker:
```bash
docker compose up -d --build
```

### 4. Підключіть сайт
У `js/config.js`:
```js
window.CONFIG = {
  USE_BOT_API: true,
  BOT_API_URL: 'https://crm.vashdomen.com/api/order',
  BOT_API_KEY: 'sk_live_довгий_випадковий_рядок',  // = SITE_API_KEY
  ...
};
```
> ⚠️ Якщо сайт відкривається по HTTPS, API теж має бути HTTPS (інакше браузер заблокує запит). Для локального тесту можна вказати `http://127.0.0.1:8080/api/order`.

Готово — заявки з сайту прилітатимуть у Telegram як картки замовлень.

## 🤖 Можливості CRM-бота

**Картка замовлення** містить: номер, дату й час, комплект, суму, ім'я, телефон (клікабельний), місто, доставку, оплату, коментар клієнта, ТТН, коментарі менеджера та статус.

**Кнопки в картці:**
- 🆕 Нове → ⚙️ Опрацювання → 🚚 Доставка → ✅ Успішно
- ❌ Відміна — бот попросить вказати причину
- ✏️ Додати/змінити ТТН
- 💬 Додати коментар (з автором і часом)
- 🔄 Оновити картку

**Команди:**
| Команда | Дія |
|---|---|
| `/new` | Створити замовлення вручну |
| `/start` | Головне меню з лічильниками |
| `/orders` | Список замовлень із фільтрами та пагінацією |
| `/stats` | Статистика: статуси, сьогодні/7/30 днів, виторг, середній чек, конверсія, причини скасувань |
| `/find запит` | Пошук за номером, телефоном, ім'ям, містом або ТТН |
| `/export` | Експорт усіх замовлень у CSV (Excel-сумісний) |
| `/cancel` | Скасувати поточну дію |

Доступ мають лише користувачі зі списку `ADMIN_IDS`. Замовлення можна надсилати в особистий чат або в групу менеджерів (`ADMIN_CHAT_ID` з мінусом).

Детальніше — у [bot/README.md](bot/README.md).

## 🧪 Перевірка

**Сайт:** заповніть форму. Якщо `USE_BOT_API: false` і токен не вказано — працює тестовий режим (подяка без відправки).

**Бот:** напишіть `/start`, потім `/stats`. Нове замовлення з'явиться в чаті автоматично.

**API вручну:**
```bash
curl -X POST https://crm.vashdomen.com/api/order \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sk_live_..." \
  -d '{"name":"Тест","phone":"+380671112233","city":"Київ","delivery":"НП №1","pack":"1 шт","price":189,"qty":1}'
```

## ❗ Якщо заявки не приходять

- Не натиснуто **/start** у боті — найчастіша причина.
- Невірний `ADMIN_CHAT_ID` (для групи починається з `-100…`).
- Бот не доданий у групу або не має прав писати.
- `BOT_API_KEY` на сайті не збігається з `SITE_API_KEY` у `bot/.env`.
- API недоступне за вказаною адресою або сайт по HTTPS звертається до HTTP.
- Перевірте логи бота: `docker compose logs -f` або вивід `python bot.py`.

## 🔐 Безпека

- Сайт і бот обмінюються ключем `X-API-Key`; без ключа API повертає 401.
- Є обмеження частоти (12 замовлень/хвилину з однієї IP).
- Не публікуйте `bot/.env` і теку `bot/data/` (там база з персональними даними).
- Для продакшену використовуйте HTTPS-проксі (Caddy/Nginx) перед портом `8080`.
